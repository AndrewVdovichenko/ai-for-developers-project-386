## Сценарий

От настройки расписания до записи в календаре владельца — один непрерывный путь из двух ролей: **Владелец** и **Гость**.

### Владелец

1. Владелец задаёт общее расписание: доступные дни недели и время внутри дня. Расписание одно на аккаунт — все типы встреч наследуют его.
2. Создаёт тип встречи: указывает название, описание и длительность *(например: Консультация — 30 минут)*.
3. Копирует ссылку на этот тип встречи и делится ею с другими пользователями.

### Гость (переходит по ссылке, регистрация не нужна)

4. Видит календарь с доступными днями и временными слотами; слоты показаны в часовом поясе, взятом из настроек браузера (то же — для владельца).
5. Выбирает день и слот — слот блокируется для остальных пользователей на время бронирования.
6. Вводит имя и email: без них запись не подтверждается.
7. Видит экран успешного бронирования с деталями встречи (тип, дата, время, часовой пояс, владелец) — либо информативное сообщение об ошибке, если слот уже занят.
8. Если бронирование не завершено, слот автоматически снова становится доступен для записи.

### Владелец (результат)

9. Успешная запись сразу появляется в разделе «Записи»: гость (имя и email), тип встречи, дата и время — без необходимости подтверждать её вручную.
10. Запись можно отменить или изменить; отменённая остаётся в списке с пометкой, а освободившийся слот снова доступен для записи.
